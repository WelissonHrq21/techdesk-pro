# TechDesk Pro - Architecture

## Backend Stack

- Node.js
- TypeScript
- Express
- PostgreSQL
- Prisma
- JWT
- Zod

## Main Layers

### Routes
Responsible for receiving HTTP requests.

### Controllers
Responsible for handling request and response.

### Services
Responsible for business rules.

### Repositories
Responsible for database access.

### Schemas
Responsible for data validation.
