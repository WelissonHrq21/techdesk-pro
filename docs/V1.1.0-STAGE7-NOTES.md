## Estrategia

- Route-based code splitting com `React.lazy`.
- `Suspense` por rota, nao global, para evitar esconder o layout inteiro durante navegacao autenticada.
- `RouteLoadErrorBoundary` para evitar tela branca se algum chunk lazy falhar.
- `LoadingScreen` ganhou `role=status`, `aria-live=polite` e texto acessivel.
- Sem `manualChunks`.
- Sem prefetch agressivo.
- Sem troca de router, framework ou bundler.
- Sem mudanca de backend.
