## Scope

Stage 8 validated TechDesk Pro v1.1.0 as a release candidate through:

- clean install from the setup package;
- upgrade from v1.0.0 images/data to v1.1.0;
- migrations on clean and populated databases;

- restart persistence;
- frontend same-origin API routing through `/api`;

No final tag, GitHub Release or push was created.

## Fixes Made During Stage 8

- Updated product/package metadata from `1.0.0` to `1.1.0`.
- Updated deploy defaults to versioned `1.1.0` images.
- Changed production frontend default API URL to `/api`.
- Added `/api` reverse proxy to the frontend Nginx image.
- Tightened `.dockerignore` to exclude nested `node_modules`, `dist`, `coverage`, logs and backups from Docker build context.
- Added npm override for `deepmerge-ts@8.0.1` to clear the Prisma audit finding while keeping Prisma `6.19.3`.
- Fixed `restore-check.ps1` validation by copying a SQL file into the Postgres container instead of passing quoted table names through PowerShell arguments.

## Environment Limitation

The Linux installer path was not fully executed in this Windows/WSL validation because the WSL shell could not access the Docker daemon used by Docker Desktop from PowerShell. The package contents and compose behavior were validated through PowerShell/Docker Desktop instead.

This does not invalidate the application, image, migration or backup evidence above, but the final RC should still be smoke-tested once on the target Linux host before publishing final release assets.
