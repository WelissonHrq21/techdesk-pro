## Limitacoes obrigatorias

1. As imagens `1.2.0-rc.1` nao foram publicadas no GHCR.
2. API e frontend RepoDigests oficiais ainda nao existem.
3. Clean install e upgrade com `docker pull` real dessas tags nao foram feitos.
4. Reboot real e autostart do host nao foram testados.
5. Permissao 600 em `/opt/techdesk-pro/.env` requer o smoke Linux nativo.

O workflow `.github/workflows/release-images.yml` exige SHA completo ja presente
no repositorio remoto e aprovado pelo CI. Publicar antes do commit e do CI
quebraria a rastreabilidade hardened. Nenhum push improvisado, tag final ou
`docker push` manual foi usado.
