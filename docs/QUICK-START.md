# Quick Start

## Recepcao

1. Acesse `Clientes` e busque o cliente pelo nome ou telefone.
2. Cadastre o cliente se ainda nao existir.
3. Cadastre ou selecione o equipamento.
4. Abra uma nova OS em `Ordens de Servico`.
5. Imprima o protocolo de entrada.
6. Copie o link de consulta publica e envie ao cliente, se aplicavel.
7. Quando houver orcamento, registre aprovacao ou rejeicao.
8. Ao fim do reparo, marque aguardando retirada e depois registre entrega.

## Tecnico

1. Abra `Ordens de Servico`.
2. Inicie a analise das OS recebidas.
3. Registre o diagnostico tecnico.
4. Crie o orcamento.
5. Envie para aprovacao.
6. Apos aprovacao, inicie a manutencao.
7. Consuma pecas pela propria OS.
8. Crie revisao de orcamento se surgir nova necessidade.
9. Finalize o servico.

## Admin

1. Configure os dados da assistencia em `Configuracoes`.
2. Crie usuarios reais em `Usuarios`.
3. Cadastre pecas em `Pecas / Estoque`.
4. Registre entradas de estoque.
5. Acompanhe historico de estoque pelo detalhe da peca.
