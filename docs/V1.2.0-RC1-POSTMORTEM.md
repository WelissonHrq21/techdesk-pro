# TechDesk Pro v1.2.0 - RC1 Post-mortem

## Status

O candidate `1.2.0-rc.1` foi bloqueado e nao foi promovido.

## Causas

1. O tar gerado por `deploy/package.sh` preservava ordem, mtimes e UID/GID do
   ambiente local. Duas execucoes com os mesmos inputs podiam gerar SHA256
   diferentes.
2. O teste de empacotamento escrevia no `dist` real e podia sobrescrever o
   artefato usado pela validacao.
3. O fluxo Linux resolvia `1.2.0-rc.1`, mas os defaults operacionais de
   PowerShell, `.env.example` e Compose ainda apontavam para `1.2.0`.

## Impacto

Nao houve impacto em release final. Nenhuma tag ou GitHub Release v1.2.0 foi
criada, a v1.1.1 permaneceu inalterada e as imagens RC1 publicadas nao foram
sobrescritas. O RC1 fica apenas como evidencia historica de um candidate
bloqueado.

## Resolucao

O RC2 usa tar e gzip deterministas, saida temporaria isolada nos testes e uma
unica identidade de pacote para materializar `VERSION`, imagens de API e
frontend, Compose, `.env.example` e instalador PowerShell. O mesmo mecanismo
continua gerando o pacote final `1.2.0` sem edicoes manuais.
